# BookMotion

Turns any text-based PDF into a narrated, animated lesson.

```bash
npm install
npm run dev
```

Open http://localhost:3000, drop in a PDF, or press **Try the sample**.

## How it works

1. **Extract** (`lib/pdf/extract.ts`): pdf.js reads the PDF in the browser, one page at a time, so large books stay light on memory and nothing is uploaded. Right-to-left (Arabic) text is rebuilt from glyph positions.
2. **Structure** (`lib/lesson/build.ts`): bookmarks and font sizes give chapters and headings; running headers, page numbers and contents rows are dropped.
3. **Detect**: definitions, formulas, shell commands, examples, numbered steps and the strongest sentences in each section.
4. **Play** (`components/`): each item becomes a scene (`components/stage/scenes.tsx`) revealed in step with the narration (`hooks/useNarration.ts`, browser speech synthesis with a silent-timer fallback).

Controls: play/pause (Space), previous/next (← →), per-chapter timeline, speed, voice, mute, subtitles, source-page viewer, chapter and scene navigation.

## Optional: AI teacher mode

Set `AI_GATEWAY_API_KEY` (Vercel AI Gateway) and an **AI teacher** button appears in the player. It rewrites the current chapter into teacher-style scenes via `app/api/enhance/route.ts`. Override the model with `AI_MODEL` (default `anthropic/claude-sonnet-5.5`).

## Notes

- Scanned PDFs (images only) have no text to extract and are rejected with a message.
- `public/sample.pdf` is generated by `node scripts/make-sample-pdf.mjs`.
